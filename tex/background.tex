\section{Error Hierarchies}

Nick Partridge gives an example of using prisms for error hierarchies in Haskell \cite{errorprisms}.

This is dual \cite{jle} to the lens kludge

\begin{verbatim}
class HasInt a where
    int :: Lens a Int
\end{verbatim}

which is known to be superseded by row types.

Both entail the globality of typeclasses and depend on esoteric compiler extensions \cite{ghc}.

The Haskell solutions are more convoluted, but it is precisely this clumsiness that attests to the appetite for a solution to this problem.
