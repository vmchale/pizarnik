\section{Subsumption}

Denote by $\prec$ the subsumption relation. A sum subsumes its constituents, i.e.

$$A \prec A \oplus B$$
$$B \prec A \oplus B$$

Subsumption is contravariant in the argument to a function type: $A -- B \prec A' -- B'$ iff $A' \prec A$ and $B' \prec B$; a function is more general if it accepts values of a more general type as argument.
